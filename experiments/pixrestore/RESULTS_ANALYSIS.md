# PixRestore 实验结果分析

使用作者公开的 PixRestore-S 单步权重，完成 4 张公开图像、3 种固定退化、3 个模型随机种子的推理。**本实验中去噪改善明显，JPEG 恢复小幅改善，双三次超分平均退步。** 这是小样本预训练推理复现，未训练模型，也未复现论文的完整基准。

论文是 [PixRestore: Unified Image Restoration via Pixel Diffusion Transformer](https://arxiv.org/abs/2608.16793)，首发于 2026-08-17，目前按预印本引用。方法与模型由论文作者提出；本项目的工作是环境适配、固定实验协议、真实推理、指标复核及结果分析。

## 数据与评价口径

输入来自 scikit-image 0.24.0 的 astronaut、coffee、chelsea、rocket。先从各自原始数组中心裁出正方形，再以 Pillow bicubic 缩放为 512×512，作为本实验 GT。除 astronaut 外，原图短边分别为 400、300、427，均包含上采样，不能称为四张原生 512 分辨率的真实高分辨率照片。原始尺寸、裁剪框、输入哈希和来源见 [manifest](data/manifest.json)。

- 超分：GT 经 bicubic 从 512 降到 128，再 bicubic 放大至 512 作为模型输入；没有附加噪声。
- 去噪：固定观测 seed 20261001–20261004，加入独立 RGB 高斯噪声 σ=25/255，裁剪到 [0,1] 后四舍五入为 8-bit PNG。同一张退化图供所有模型种子使用。
- JPEG：quality=10、4:2:0 色度抽样、optimize=False，解码为 RGB PNG。JPEG 去伪影不在论文原八类任务中，仅作为额外泛化检查。

所有指标在完整 512×512 RGB 上计算，不裁边、不转 Y 通道。GT 与输入由 uint8/255 转为 float；恢复结果先裁剪到 [0,1]，直接计算浮点 PSNR/SSIM，再另存量化 PNG。SSIM 使用 scikit-image 默认 7×7 均匀窗口和样本协方差。存档 `.npy` 保留裁剪前的输出，便于独立复核。

## 主随机种子结果

以下均为 base seed=20261116 时四张图的均值。实际模型 seed 等于 base seed 加图像索引。PSNR 单位为 dB，SSIM 无单位，两者越高越好。

| 任务 | 输入 PSNR | 恢复 PSNR | ΔPSNR | 输入 SSIM | 恢复 SSIM |
|---|---:|---:|---:|---:|---:|
| 4×双三次超分 | 29.1804 | 28.2111 | -0.9693 | 0.863291 | 0.839130 |
| 高斯去噪 σ=25/255 | 20.6136 | 33.2621 | +12.6484 | 0.268898 | 0.901573 |
| JPEG Q=10 额外检查 | 28.5409 | 29.3894 | +0.8484 | 0.809112 | 0.849342 |

去噪平均增加 12.6484 dB，但本实验没有加入 BM3D、其他恢复网络等强基线，所以这只证明相对含噪输入的改善，不能证明优于已有去噪方法。JPEG 平均增加 0.8484 dB，四图都提高，但不能推广到任意压缩级别、图像域或混合退化。

超分平均下降 0.9693 dB，四图中三图下降。逐图数据保留如下，避免均值掩盖失败样例。

| 图像 | 超分 ΔPSNR | 去噪 ΔPSNR | JPEG ΔPSNR |
|---|---:|---:|---:|
| astronaut | -0.4645 | +10.7998 | +0.7702 |
| coffee | +0.2777 | +12.3152 | +1.5675 |
| chelsea | -2.8370 | +13.2670 | +0.6152 |
| rocket | -0.8536 | +14.2117 | +0.4409 |

chelsea 的超分 PSNR 从 32.2961 降至 29.4591 dB，SSIM 从 0.843164 降至 0.787565。模型对局部纹理的重建与 GT 不一致，应结合全图和同位置裁剪观察，不能只因边缘更锐就判为恢复成功。生成式恢复追求感知质量，确实可能与像素保真存在冲突；但本次没有测 LPIPS 或开展盲评，因此不能反过来断言这些 PSNR 下降已经换来了感知提升。

失败的可能原因包括自定义 bicubic 退化与训练/真实 SR 分布不同、GT 上采样带来的纹理统计变化，以及模型的生成先验。当前实验没有逐项控制这些因素，以上只是待验证假设，不是已证明的因果结论。

## 随机种子稳定性

三个 base seed 为 20261116、20261216、20261316。每个值先在四张图上取均值，再在三个种子间计算样本标准差。

| 任务 | 三个种子的四图均值 PSNR / dB | 样本标准差 / dB |
|---|---:|---:|
| 4×双三次超分 | 28.2061 | 0.0052 |
| 高斯去噪 σ=25/255 | 33.2635 | 0.0024 |
| JPEG Q=10 额外检查 | 29.3986 | 0.0082 |

标准差较小，表明这些固定观测上的输出指标对本次种子变化不敏感。它不是泛化误差、置信区间，也不能把 36 个输出当成 36 张独立测试图。固定 seed 的三次重复推理输出最大绝对差为 0；该结论仅适用于已记录的软件和硬件，跨版本/平台不保证逐位相同。

## 路由与运行成本

[router_weights.json](results/router_weights.json) 记录官方路由器的六层预测权重。采集方式是只读 forward hook，不修改网络返回值；它对应仅由 LQ 推断的 p，而非训练中需要 HQ 的目标 q。记录层索引为零基 [1,2,4,6,8,10]。观测权重不能单独证明某层对恢复质量的因果作用，需要控制变量消融进一步检验。

RTX 3060 Laptop 6GB、batch=1、BF16 autocast、FP32 权重存储、NFE=1。完整恢复调用包括 DINO 特征提取与一次 DiT 评估，采用一次全局预热、每配置三次 CUDA 同步计时的中位数，再对图像平均。主 seed 三个任务分别为 101.59、99.83、101.10 ms/图；三种子全部运行平均约 101 ms/图。

计时不含权重加载、图像预处理、指标和磁盘 I/O。峰值 PyTorch allocated 约 326.93 MiB，reserved 最高 376 MiB；这不是整个进程或显卡总显存占用，不含 CUDA 上下文等外部开销。恢复网络 31,645,421 参数，加冻结 DINO 22,056,576，共 53,701,997，吻合论文的 53.70M。NFE=1 不代表整个系统只有一次神经网络前向。

论文 Table 3 的 44 ms 来自 A800、5 次预热后 100 次平均，与本机硬件及计时协议不同，不能据此直接推断硬件速度比例或声称严格复现论文时延。

## 复现边界与后续实验

官方模型、采样器源码保持不变，两个模型均严格加载权重。Windows / torch 2.1 不支持这里的 torch.compile，外层适配器将可选编译装饰器改为 eager 执行；采用单 GPU 推理，替换作者本地路径，添加测量与存档逻辑。固定上游 commit、权重 SHA256、配置、包版本均随结果记录。

论文使用八类恢复任务、15 个配对 benchmark，按数据集和任务汇总。本次只有四张固定图；RealSR/ScreenSR 与 bicubic 合成 SR 也不同。不能将这里的 33.2621 dB 与论文去噪 34.87 dB 直接作复现差距计算，更不能称复现了论文全部结论。

后续优先扩大公开测试集，采用原生高分辨率 GT 和作者原协议；加入同输入的强基线，再补充 LPIPS 与盲评；按预先固定的图像分组分析失败率。若研究路由贡献，应获取训练前/消融权重或按作者协议重训。把最终单步微调权重改为多步采样，不等于复现论文微调前模型的步数消融。

## 如何独立复核

按 [README](README.md) 安装 CPU 评价依赖后运行 `python verify_results.py`。该脚本重新读取 GT、输入及浮点输出，核对逐图 CSV、汇总 JSON、保存 PNG、种子统计和输入哈希；不需要 GPU 或模型权重。运行方法和所有原始数值见 [metrics.csv](results/metrics.csv) 与 [summary.json](results/summary.json)。
